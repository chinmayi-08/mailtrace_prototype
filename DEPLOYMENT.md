# MailTrace deployment quick guide

## Render — Web Service

1. Push this folder to GitHub.
2. In Render, create a **New Web Service**.
3. Connect the repository.
4. Build Command: leave blank.
5. Start Command: `node server.js`.
6. Deploy.
7. Open the Render URL.

## Demo backup

Always keep the exact same project locally on the presentation laptop. Test both the online URL and `http://localhost:3000` before the SIH presentation.

## What to show judges

Use the browser website. Do not present VS Code as the product. VS Code is only the development environment.
